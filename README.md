# Manual Search SDK

Java17 / Apache Lucene9.12.1 / Maven3.9.15 project scaffold.

Run Maven from this project directory. `.mvn/maven.config` selects the project-local dependency repository `.m2/repository`.

```sh
mvn test
mvn package
```

Dependencies include Lucene core, analysis-common, queryparser, highlighter and JUnit Jupiter5.11.4. Business implementation is not yet present.
